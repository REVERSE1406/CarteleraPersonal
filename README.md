# Mi Cartelera Personal

Aplicación React + TypeScript (Vite) con autenticación de Supabase.

## Configuración

1. Copia `.env.example` a `.env` y completa las claves de tu proyecto (Dashboard de Supabase → Project Settings → API):

```
VITE_SUPABASE_URL=https://tu-proyecto.supabase.co
VITE_SUPABASE_ANON_KEY=tu_anon_key
```

2. Instala dependencias y arranca el servidor:

```bash
npm install
npm run dev
```
