# 🎬 Mi Cartelera Personal

Aplicación web Full-Stack desarrollada con **React, TypeScript y Vite** que permite a cada usuario registrar, organizar y calificar las películas y series que quiere ver, está viendo, o ya vio. La aplicación consume la API pública de **The Movie Database (TMDB)** para buscar títulos reales y permite persistir la información de manera segura en una base de datos relacional en **Supabase**, protegida mediante autenticación y políticas de seguridad RLS.

---

## 🚀 Tecnologías Requeridas y Arquitectura

- **Frontend:** React + TypeScript (Vite), componentes con props e interfaces tipadas.
- **API Externa:** The Movie Database (TMDB) para búsqueda de películas y series, pósters, sinopsis y metadatos.
- **Autenticación:** Supabase Auth (Registro, login, logout y manejo de sesión persistente).
- **Base de Datos y Seguridad:** Supabase (PostgreSQL) con la tabla `mi_lista` y políticas estrictas de **Row Level Security (RLS)** por usuario.

---

## 📋 Requisitos Previos

- **Node.js** (versión 20 o superior recomendada)
- Un proyecto configurado en [Supabase](https://supabase.com)
- Una API Key de [The Movie Database (TMDB)](https://www.themoviedb.org/settings/api)

```bash

2. Configurar las variables de entorno

Fragmento de código

🗄️ Base de Datos
En el dashboard de tu proyecto en Supabase, abre el SQL Editor y ejecuta el script contenido en supabase/migrations/001_mi_lista.sql. Esto creará la tabla mi_lista con la siguiente estructura y activará las políticas de seguridad RLS:
SQL
create table mi_lista (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users(id) on delete cascade not null,
  tmdb_id integer not null,
  titulo text not null,
  poster_url text,
  tipo_contenido text check (tipo_contenido in ('pelicula', 'serie')) not null,
  estado text check (estado in ('por_ver', 'viendo', 'vista')) not null,
  calificacion_personal integer check (calificacion_personal between 1 and 5),
  comentario text,
  fecha_agregada timestamptz default now() not null
);

alter table mi_lista enable row level security;

create policy "Usuarios pueden ver su propia lista" on mi_lista for select using (auth.uid() = user_id);
create policy "Usuarios pueden insertar en su propia lista" on mi_lista for insert with check (auth.uid() = user_id);
create policy "Usuarios pueden actualizar su propia lista" on mi_lista for update using (auth.uid() = user_id);
create policy "Usuarios pueden eliminar de su propia lista" on mi_lista for delete using (auth.uid() = user_id);
💻 Uso de la Aplicación
```
